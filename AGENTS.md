# Сверка врачей

Локальное приложение с FastAPI на Python 3.11+ в `backend/` и отдельным React-интерфейсом в `frontend/`. Точка входа для backend — `backend/app.py`. Инструкции для запуска и адрес страницы находятся в README.md.

- Загружай не более 200 специалистов через пагинацию Medical API. Ключ бери из серверной переменной `MEDICAL_API_KEY`. Локальный `.env` игнорируется Git. Не выводи ключ в логи, HTML, JavaScript и материалы для сдачи.
- Читай Doctor Catalog из HTML-карточек. Сохраняй исходное написание полей для показа на странице, нормализацию выполняй только при поиске и сопоставлении.
- Точное совпадение требует однозначного соответствия по полному ФИО и специальности. Инициалы, опечатки и несколько кандидатов требуют объяснения в интерфейсе.
- Статус «только в одном источнике» относится к загруженной выборке. При ошибке источника сохраняй предыдущую успешную сверку.
- При изменении загрузки или сопоставления запусти `python -m unittest discover -s tests` из папки `backend/`. Для проверки интерфейса открой страницу, выбери врача, выполни поиск и обнови данные.
